# 日記 — 使い方

思いついたらすぐ書ける、自分専用の日記アプリです。

- ネットにつながっていなくても、開く・書く・保存するができます
- ネットにつながったときに、Mac と iPhone の日記を自動でそろえます（同期）
- 同期のときは日記を暗号化してから送るので、保管先の GitHub 上では中身を読めません

## 1. ふだんの使い方

### 新しく書く
- 右上の **「＋ 書く」** を押すと、今日の日付が入った新しい日記が開き、すぐに本文を書き始められます。
- iPhone では画面右下の丸い **「書く」** ボタンです。
- Mac では一覧画面で **N** キーを押しても新しく書けます。

### 日付を変える
- 日付の欄を押すと、カレンダーから好きな日付を選べます。曜日も自動で変わります。
- 日付が今日以外になっているときは **「今日」** ボタンが出ます。押すと今日の日付に戻ります。

### 題と本文
- 題はなくてもかまいません。題がない日記は、一覧では本文の 1 行目が見出しになります。
- 題を書いて **Enter**（改行キー）を押すと、本文に移ります。
- 右上に字数が出ます（空白と改行は数えません）。

### 保存
- **保存ボタンはありません。** 書いたそばから自動で保存されます。
- 何も書かずに一覧へ戻った日記は、自動で消えます。

### 一覧へ戻る
- 左上の **「← 一覧」** を押します。Mac では **Esc** キーでも戻れます。

### 一覧と検索
- 日記は新しい順に、月ごとにまとまって並びます。日曜は赤、土曜は青で表示されます。
- 上の検索欄に言葉を入れると、題か本文にその言葉を含む日記だけが表示されます。
- 1 日に何篇でも書けます。

### 削除
- 日記を開いて右上の **「削除」** を押し、もう一度押すと削除されます（3 秒以内に押さなければ取り消されます）。
- 削除は同期で他の端末にも伝わります。

## 2. 同期の状態表示

一覧画面の右上に、同期の状態が表示されます。押すとその場で同期します。

| 表示 | 意味 |
|---|---|
| ● 同期済み 12:34 | 最後に同期した時刻です。 |
| ● 同期中… | GitHub とやりとりしています。 |
| ● オフライン（あとで同期） | ネットにつながっていません。書いた日記は端末に保存されていて、つながったら自動で同期します。 |
| ● 同期できません | 設定かトークンに問題があります。押すと設定画面に移り、理由が表示されます（[困ったとき](#5-困ったとき)）。 |
| 同期：未設定 | まだ同期を設定していません。押すと設定画面に移ります。 |

同期は次のときに自動で行われます。

- アプリを開いたとき・アプリに戻ってきたとき
- 書き終えて一覧に戻ったとき、書いている途中に手を止めたとき
- ネットにつながったとき
- 開いている間は 2 分ごと

## 3. はじめての設定

最初に一度だけ行います。必要なものは GitHub の無料アカウントだけです。

### 3-1. アプリを公開する（GitHub Pages）

1. GitHub にログインし、右上の **「＋」→「New repository」** を選びます。
2. Repository name に **`diary`** と入れ、**Public** を選んで **「Create repository」** を押します。
3. 次の画面の **「uploading an existing file」** を押します。
4. `diary-app` フォルダを開き、**中のファイルをすべて選んで**ドラッグし、**「Commit changes」** を押します。
   - フォルダごとではなく、中身（`index.html`、`sw.js` など）をドラッグしてください。
5. リポジトリの **「Settings」→ 左の「Pages」** を開きます。
6. 「Branch」を **`main`** と **`/ (root)`** にして **「Save」** を押します。
7. 1〜2 分待つと、`https://ユーザー名.github.io/diary/` でアプリが開けるようになります。

> ここで公開されるのはアプリの仕組みだけです。日記の中身は含まれません。

### 3-2. 日記の保管場所を作る

1. もう一度 **「＋」→「New repository」** を選びます。
2. 名前は **`diary-data`**、**Private** を選び、**「Add a README file」にチェック**を入れて作成します。

### 3-3. アクセストークンを作る

アプリが `diary-data` に日記を保存するための鍵です。

1. 右上の自分のアイコン → **「Settings」** → 左の一番下 **「Developer settings」** を開きます。
2. **「Personal access tokens」→「Fine-grained tokens」→「Generate new token」** を押します。
3. 次のように設定します。
   - **Token name**：`diary` など分かりやすい名前
   - **Expiration**：長め（例：1 年）
   - **Repository access**：**Only select repositories** → **`diary-data`** だけを選ぶ
   - **Permissions**：**Contents** を **Read and write** にする
4. **「Generate token」** を押し、表示された `github_pat_…` で始まる文字列をコピーします。
   - **この文字列は一度しか表示されません。** すぐにメモしてください。

### 3-4. Mac に追加する

1. **Safari** で `https://ユーザー名.github.io/diary/` を開きます。
2. メニューの **「ファイル」→「Dock に追加」** を選びます。
3. Dock に追加された **「日記」アイコンから開き**、一覧の下の **「同期とバックアップの設定」** を開きます。
4. 次の 4 つを入れて **「保存して同期」** を押します。
   - GitHub のユーザー名
   - リポジトリ名（`diary-data`）
   - アクセストークン（3-3 でコピーしたもの）
   - 暗号化パスワード（自分で決める。**全端末で同じもの**）

### 3-5. iPhone に追加する

1. **Safari** で `https://ユーザー名.github.io/diary/` を開きます。
2. 下の **共有ボタン（□に↑）→「ホーム画面に追加」** を押します。
3. ホーム画面の **「日記」アイコンから開き**、3-4 の 3〜4 と同じように設定します。
   - 暗号化パスワードは Mac と同じものを入れてください。

> **必ず追加したアイコンから開いてください。** Safari のタブで開いた日記と、アイコンから開いた日記は別々に保存されます。

### 3-6. 以前の diary.html の日記を移す

1. 以前の `diary.html` を開き、**「バックアップを書き出す」** を押します。
2. 新しいアプリの **「同期とバックアップの設定」→「バックアップから読み込む」** で、そのファイルを選びます。
3. 自動で同期され、他の端末にも反映されます。

## 4. バックアップ

**「同期とバックアップの設定」** 画面から使えます。

- **バックアップを書き出す**：すべての日記を 1 つのファイル（`diary-backup-日付.json`）に保存します。このファイルは暗号化されていないので、保管場所に気をつけてください。
- **バックアップから読み込む**：書き出したファイルから日記を戻します。今ある日記は消えず、足りないものが追加され、新しいほうの内容が残ります。

同期していれば GitHub にも日記が残っています。端末を買い替えたり、ブラウザのデータを消してしまったりしても、同じ設定を入れ直せば戻ります。

## 5. 困ったとき

「同期できません」と出たときは、設定画面に理由が表示されます。

| 表示される理由 | 対処 |
|---|---|
| トークンが正しくないか、有効期限が切れています | 3-3 の手順でトークンを作り直し、各端末の設定に入れ直します。 |
| リポジトリが見つかりません | ユーザー名・リポジトリ名の綴りを確認します。トークンの「Repository access」に `diary-data` が入っているかも確認します。 |
| トークンに書き込みの権限がありません | トークンの「Contents」を **Read and write** にします。 |
| 暗号化パスワードが違います | 他の端末と同じ暗号化パスワードを入れます。 |
| 接続回数の上限に達しました | しばらく待てば自動で再開します。 |

### その他

- **iPhone で書いた日記が Mac に出ない**：一覧右上の同期表示を押すと、すぐに同期します。
- **アプリを更新した**：GitHub の `diary` リポジトリのファイルを差し替えると、各端末ではアプリを **2 回開き直したあと**に新しい版になります。
- **暗号化パスワードを変えたい**：1 台で新しいパスワードを入れて「保存して同期」を押します。ほかの端末では「暗号化パスワードが違います」と出るので、同じ新しいパスワードを入れます。
- **その端末で同期をやめたい**：設定画面の「この端末の同期をやめる」を押します。端末の中の日記は残ります。

---

## 6. しくみと注意点

- 日記はまず **その端末の中** に保存され、同期のときに暗号化されて GitHub の非公開リポジトリ `diary-data` の `entries.json` に保存されます。
- 暗号化には AES-256-GCM を使っています。鍵は暗号化パスワードから作られ、パスワードそのものは GitHub に送られません。
- **暗号化パスワードを忘れると、GitHub に保管した日記は誰にも戻せません。** パスワード管理アプリなどに控えておいてください。
- アクセストークンと暗号化パスワードは、各端末の中にだけ保存されます。端末を人に貸すときなどは気をつけてください。
- 2 台で同じ日記を同時に書き換えた場合は、**あとから保存したほう** が残ります。
- 公開リポジトリ `diary` に入っているのはアプリの仕組みだけで、日記の中身は含まれません。
