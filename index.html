使い方

書く

  • 「＋ 書く」（iPhone では右下の丸いボタン）を押すと、今日の日付で新しい日記が開きます。Mac では一覧で N キーでも書けます。
  • 日付の欄を押すと、好きな日付に変えられます。「今日」ボタンで今日に戻ります。
  • 題はなくてもかまいません。題で Enter を押すと本文に移ります。
  • 保存ボタンはありません。書いたそばから自動で保存されます。何も書かずに戻った日記は消えます。
  • 「← 一覧」（Mac では Esc）で一覧に戻ります。

読む・探す・消す

  • 日記は新しい順に、月ごとに並びます。1 日に何篇でも書けます。
  • 上の検索欄に言葉を入れると、題か本文にその言葉を含む日記だけが出ます。
  • 削除は、日記を開いて右上の「削除」を 2 回続けて押します。削除は他の端末にも伝わります。

同期

  • ネットにつながっていなくても書けます。つながったときに、Mac と iPhone の日記が自動でそろいます。
  • 右上の表示：同期済み＝最後に同期した時刻／オフライン＝つながったら自動で同期／同期できません＝押すと理由が出ます。押すとその場で同期します。
  • 日記は暗号化してから GitHub に送るので、GitHub 上では中身を読めません。
  • 暗号化パスワードを忘れると、GitHub に保管した日記は戻せません。どこかに控えておいてください。
  • iPhone では、ホーム画面に追加した「日記」アイコンから開いてください（Safari のタブとは別に保存されます）。

はじめての設定（概要）

  1. GitHub に公開リポジトリ diary を作り、アプリのファイルを入れて「Pages」で公開する。
  2. 非公開リポジトリ diary-data を作る（README つき）。
  3. Fine-grained トークンを作る（diary-data だけ・Contents を Read and write）。
  4. Mac は Safari の「ファイル → Dock に追加」、iPhone は Safari の「共有 → ホーム画面に追加」。
  5. 追加したアイコンから開き、「同期とバックアップの設定」で 4 項目を入れて「保存して同期」。

くわしい手順と困ったときの対処は、アプリのファイルに入っている README.md にあります。

バックアップ

  • 「同期とバックアップの設定」から、日記をファイルに書き出したり、ファイルから戻したりできます（書き出したファイルは暗号化されていません）。
  • 以前の diary.html で書き出したファイルも読み込めます。

同期

日記はこの端末の中に保存され、ネットにつながったときに GitHub の非公開リポジトリを通して他の端末と同期します。送る前に暗号化パスワードで暗号化するので、GitHub 上では中身は読めません。

この端末の中にだけ保存されます。
すべての端末で同じものを入れてください。忘れると、GitHub に保管した日記は誰にも戻せなくなります（各端末の中の日記は読めます）。
